## Overview

Sugar Bytes Guitarist is a MIDI effect plugin that generates realistic guitar strumming patterns from chord input, making it easy to program convincing guitar rhythms without a real guitar.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes Guitarist** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Strum Patterns** | Library of realistic up-down strumming rhythms with variable timing |
| **Chord Input** | Single-note MIDI input triggers full chord voicings from built-in library |
| **Humanize** | Random timing and velocity variations for a live-played feel |
| **MIDI Output** | Sends strum MIDI to any guitar instrument plugin or sampler |
